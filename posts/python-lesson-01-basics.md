## Core Theory

### Definition: Programming
**Programming** is the act of writing **exact, step-by-step instructions** that a computer follows to perform a task.

Key facts:
- A computer has **no intelligence**
- It executes instructions **literally**
- One wrong instruction = wrong result or program crash

Programming exists to:
- Automate repetitive work
- Solve problems systematically
- Control hardware using logic

---

### Definition: Python
**Python** is a **high-level, interpreted programming language** designed to be:
- Easy to read
- Easy to write
- Powerful in real systems

Python is not:
- A tool
- A software
- An AI

Python **is a language** used to write programs.

---

### Why Python Exists
Older languages:
- Required more lines of code
- Had complex syntax
- Slowed development

Python was created to:
1. Reduce syntax noise
2. Improve readability
3. Let developers focus on **logic, not rules**
4. Speed up development

---

## Internal Working / Logic

### How Python Executes Code
1. You write Python code
2. Python **Interpreter** reads it **line by line**
3. Each line is:
   - Checked for syntax
   - Converted into bytecode
   - Executed immediately

Important:
- Execution is **top to bottom**
- Python **stops at the first error**

---

### Interpreter vs Compiler
- **Compiler**: Translates full program at once (C, C++)
- **Interpreter**: Translates & runs line-by-line (Python)

Python internally:
- Converts code → bytecode
- Executes using Python Virtual Machine (PVM)
