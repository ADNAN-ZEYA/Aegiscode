# Cybersecurity Roadmap for Beginners  
### A Complete Step-by-Step Guide (Beginner → Intermediate)

Cybersecurity, also known as **Information Security**, is the practice of protecting systems, networks, applications, and data from cyber threats such as hacking, malware, phishing, ransomware, and data breaches.

In today’s digital world—where cloud computing, online payments, AI systems, and remote work dominate—**cybersecurity has become one of the most in-demand and future-proof career options**.

This guide is created by **AegisCode** to help:

- Students (CS / IT / Non-IT)
- Absolute beginners with zero background
- Career switchers
- Anyone looking for a **clear, structured, and practical cybersecurity roadmap**

---

## 🚀 Phase 1: Foundations (Start Here)

Strong fundamentals are **mandatory** in cybersecurity.  
Skipping basics is the most common reason beginners struggle later.

---

## 1️⃣ Learn Linux Basics (Mandatory Skill)

Linux is the backbone of cybersecurity.  
Most servers, security tools, and penetration testing environments run on Linux.

### Why Linux matters in cybersecurity
- Web and cloud servers run on Linux
- Most security tools are Linux-based
- Ethical hackers and attackers both use Linux
- Industry labs and simulations depend on Linux

### What you must learn
- Linux file system (`/etc`, `/var`, `/home`)
- File permissions (read, write, execute)
- Users and groups
- Process management
- Package managers (`apt`, `yum`)
- Environment variables
- Bash shell basics

### Important Linux commands
- ls, cd, pwd
- cp, mv, rm, cat, less
- chmod, chown
- ps, top, htop, kill
- grep, find
- ssh, scp, curl, wget


**Goal:**  
Be confident working in a Linux terminal without relying on GUI tools.

---

## 2️⃣ Networking Fundamentals (Non-Negotiable)

Every cyber attack happens over a network.  
Without networking knowledge, cybersecurity will never make sense.

### Core networking concepts
- OSI Model (all 7 layers)
- TCP/IP Model
- IP addressing and subnetting
- MAC addresses
- TCP vs UDP
- DNS resolution
- HTTP vs HTTPS
- Firewalls and NAT
- Routers and switches (basics)

### Networking tools to practice
- ping
- traceroute
- netstat / ss
- ip a / ifconfig
- Wireshark


**Goal:**  
Understand how data flows, where attacks occur, and how traffic is analyzed.

---

## 3️⃣ Programming Basics for Cybersecurity

You don’t need to be a software engineer, but **scripting is mandatory**.

### Best languages to start with
- **Python** – automation, exploits, security tools
- **JavaScript** – web vulnerabilities like XSS
- **Bash** – Linux automation and scripting

### Programming concepts to learn
- Variables and data types
- Loops and conditional logic
- Functions
- File handling
- HTTP requests and APIs
- Basic debugging

**Goal:**  
Read, understand, and modify simple exploit or automation scripts.

---

## 🌐 Phase 2: Web Application Security (Core Skill)

Most real-world cyber attacks target **web applications**.

---

## 4️⃣ Web Fundamentals (Before You Hack)

Never attack something you don’t understand.

### Learn how websites work
- HTML basics
- CSS basics
- JavaScript execution in browsers
- Client–server communication
- Cookies and sessions
- Authentication vs Authorization
- REST APIs and JSON
- HTTP request methods

**Goal:**  
Understand how data moves inside a web application.

---

## 5️⃣ OWASP Top 10 Vulnerabilities

The OWASP Top 10 lists the most critical web security risks worldwide.

### Must-learn vulnerabilities
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Broken Authentication
- Broken Access Control
- Insecure File Upload
- Command Injection
- Security Misconfiguration

### Safe practice platforms
- DVWA
- OWASP Juice Shop
- PortSwigger Web Security Academy

**Goal:**  
Exploit vulnerabilities ethically and understand **why they exist**.

---

## 🛠️ Phase 3: Cybersecurity Tools

Tools support skills—but **tools alone do not make you a hacker**.

---

## 6️⃣ Essential Cybersecurity Tools

### Network & scanning tools
- **Nmap** – port and service scanning
- **Nikto** – web server vulnerability scanning

### Web security tools
- **Burp Suite** – HTTP interception and testing
- **Gobuster** – directory and file brute forcing

### Exploitation tools
- **Metasploit** – exploitation framework
- **Hydra** – password attack automation

**Goal:**  
Understand what each tool does, when to use it, and its limitations.

---

## 🧠 Phase 4: Operating Systems & Environments

---

## 7️⃣ Kali Linux

Kali Linux is the industry-standard OS for ethical hacking.

### Learn
- Kali tool categories
- Virtual machines (VMware / VirtualBox)
- Networking inside VMs
- Lab setup and practice environments

**Goal:**  
Comfortably perform security labs using Kali Linux.

---

## 8️⃣ Operating System Security Basics

### Important topics
- Windows security fundamentals
- Linux hardening
- File permission abuse
- Sudo misuse
- Privilege escalation basics
- Patch and update management

**Goal:**  
Understand how attackers escalate privileges inside systems.

---

## 🔐 Phase 5: Defensive Security (Blue Team Basics)

Cybersecurity is not only about attacking systems.

---

## 9️⃣ Blue Team Fundamentals

### Learn
- What is a SOC (Security Operations Center)
- SIEM basics (Splunk introduction)
- Log analysis
- Incident response lifecycle
- Malware basics
- Antivirus and EDR concepts

**Goal:**  
Understand how attacks are detected, analyzed, and mitigated.

---

## ☁️ Phase 6: Cloud Security

Most modern infrastructure runs on cloud platforms.

---

## 🔟 Cloud Security Basics

### Learn
- Cloud fundamentals (AWS / Azure)
- IAM (Identity and Access Management)
- S3 bucket security
- Security groups
- Cloud misconfiguration risks

**Goal:**  
Identify common cloud security mistakes attackers exploit.

## 🧪 Phase 7: Practice & Real-World Learning

## 1️⃣1️⃣ Hands-On Practice Platforms

- Capture The Flag (CTFs)

**Goal:**  
Develop an attacker mindset with defensive awareness.

---

## 🧭 Career Paths in Cybersecurity

After building foundations, you can specialize as a:

- Ethical Hacker / Penetration Tester
- SOC Analyst
- Application Security Engineer
- Cloud Security Engineer
- Digital Forensics Analyst
- Security Researcher

---

## ✅ Final Advice from AegisCode

- Do not rush tools
- Foundations matter more than certificates
- Practice daily (1–2 hours minimum)
- Learn **why attacks work**
- Document your learning (blogs, notes, reports)
- Stay ethical and legal
